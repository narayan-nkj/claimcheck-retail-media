# AMD Developer Hackathon ACT III — Official Event Verification

**Verification date:** 16 October 2026

## Current verified facts

Source: [official ACT III event page](https://lablab.ai/ai-hackathons/amd-developer-hackathon-act-iii)

- Online build phase: 12–18 October 2026.
- Selected onsite phase: 17–18 October 2026 in Rome, Milan, and Imperia.
- Current page headline prize pool: **$17,000+**. Do not use the earlier $12,000+ figure unless the page changes again.
- The event is presented as building AI agents and high-performance AI applications on AMD GPUs in the cloud.
- The page describes AMD GPUs in the cloud with the ROCm software stack.
- AMD is required for prize eligibility; a meaningful AMD workload must be part of the working product shown to judges.
- Tracks include Intelligent Industry, Health and Wellbeing, Reinvent Commerce, and Create a New Kind of Experience.
- ClaimCheck is planned for Reinvent Commerce, subject to team selection and organizer rules.
- Reinvent Commerce requires a real customer or merchant problem and a useful commercial recommendation or action. Forecasting is not automatically required; if forecasting is used, the calculation must be explained and an LLM cannot be the only forecasting method.
- The judging content emphasizes Application of Technology, Presentation, Business Value, and Originality. Confirm exact event-specific scoring if the submission form provides different weights.
- The event page FAQ references `notebooks.amd.com/tokenfactory` and states that a credit card is not needed for the event. Do not make the $100 credit a critical dependency.

## Submission and rule sources

Source: [lablab.ai Hackathon Rule Book](https://lablab.ai/hackathon-rules)

The standard submission package includes a clear title, short and long descriptions within the form limits, technology/category tags, presentation media, public GitHub repository, demo platform, and application URL. The rule book states that video is normally MP4 or MOV and slides are PDF. The event form takes priority if it differs.

The rule book also warns that submission non-compliance can reduce scores or cause exclusion, and requires ethical/original work. Dependency licenses, attribution, repository visibility, secrets, and generated assets must be reviewed before submission.
