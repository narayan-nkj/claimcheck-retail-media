# ACT III Stop/Go Checklist

## GO only when all pass

- [ ] Live submission cutoff and form fields verified.
- [ ] Team approval and track selection verified.
- [ ] AMD target/account/quota/model path works.
- [ ] Meaningful AMD workload is visible in the product demo.
- [ ] AMD provenance artifacts are saved without secrets.
- [ ] Curated stale/conflicting/missing evidence cases have zero false accepts.
- [ ] Every decision has a replayable evidence chain and human-readable reason.
- [ ] Public GitHub repository and README work from a clean environment.
- [ ] Demo URL works without private credentials.
- [ ] Video, PDF slides, cover image, descriptions, tags, and application URL are ready.
- [ ] License, attribution, originality, and secret checks pass.

## STOP or re-scope when any fail

- AMD is only asserted, not demonstrated.
- The demo depends on unavailable live merchant credentials.
- The product requires universal legal-compliance claims.
- Unsupported, stale, or contradictory claims can pass.
- Required public artifacts cannot be published.
- The remaining time cannot prove and package the narrow slice.
