# ClaimCheck `.brain` Planning Workspace

This is a planning scaffold for the AMD Developer Hackathon ACT III ClaimCheck project.

The tailored three-worker/two-tester planning prompt is stored at:

`AMD_ClaimCheck_Project_Planning_Prompt.md`

Populate `.ORG_research/`, `.research/`, and `.demo/` with the project inputs before executing the planning workflow. No research conclusions, implementation claims, or completed phase plans have been fabricated in this scaffold.

## Team model

- Worker 01: Core policy and evidence engine
- Worker 02: AMD model-serving and generation path
- Worker 03: Web application, evaluation, demo, and release workflow
- Tester 01: Functional and system validation
- Tester 02: Integration, regression, evidence, and release validation
